LDR (bare 2-pin) — light sensor
LDR pin 1 → 3.3V (VCC)
LDR pin 2 → GPIO32 (midpoint)
10kΩ resistor → GPIO32 → GND

Wired as a voltage divider:
3V3 —[LDR]—GPIO32—[10k]—GND
Note: bright = high ADC, dark = low ADC (0 = dark, 4096 = full bright)
Auto LED thresholds: ≥2000 = off, ≤100 = max, 100-2000 = gradual
Actuators / drivers
L298N — Channel A: Grow LED (PWM dimming)
GPIO25 → IN1 (direction, held HIGH)
GPIO26 → ENA (PWM = LED brightness 0-255)
IN2 → GND (fixed direction)
OUT1/OUT2 → LED + / LED -

PWM on ENA pin with IN1=HIGH/IN2=LOW dims the LED smoothly via L298N.
Peltier module (heater / water purifier) — HJR-3FC relay
GPIO19 → relay IN
5V → relay VCC   GND → relay GND (share with ESP32)
Relay COM ← 12V PSU +   Relay NO → Peltier +/red
Peltier -/black ← 12V PSU -

On/off relay switching (no PWM). Red wire = 12V HOT, black = GND. Jumper = high trigger.
L298N — Power / common (Channel A = Grow LED only)

GND terminal → supply GND + ESP32 GND
5V OUT → leave unused (12V input mode)
